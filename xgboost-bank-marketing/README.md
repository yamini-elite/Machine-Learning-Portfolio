# 📊 Bank Marketing Prediction using XGBoost

An end-to-end Machine Learning classification project that predicts whether a bank customer is likely to subscribe to a term deposit.

This project focuses not only on training an XGBoost model, but also on solving real-world ML problems such as **class imbalance, precision-recall trade-offs, hyperparameter tuning, threshold tuning, feature engineering, cross-validation, and data leakage**.

---

## 🎯 Problem Statement

Banks run marketing campaigns to identify customers who are likely to subscribe to a term deposit.

The objective of this project is to predict whether a customer will subscribe.

y
